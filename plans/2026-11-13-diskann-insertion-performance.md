## 3. Evidence and technical constraints

Current source was read to establish the following, rather than assuming old paths remain current:
- [GraphStore](<../vectorlite/src/diskann_core.rs#L43-L88>) has raw-slice scalar/batch vector callbacks and scalar neighbor writes. The vendor [bulk seam](<../third_party/diskann-0.60.0/vendor/src/provider.rs#L384-L403>) defaults to sequential scalar writes; upstream allowing out-of-order commits does not establish that SQLite can safely do so.
- [Stored-vector decoding](<../vectorlite/src/diskann_store.rs#L376-L410>) checks lengths/finiteness; [beam scoring](<../vectorlite/src/diskann_core.rs#L1012-L1032>), [owned fetch](<../vectorlite/src/diskann_core.rs#L437-L447>), and [prune fill](<../vectorlite/src/diskann_core.rs#L1300-L1391>) also validate. This is a candidate duplicate scan, not permission to trust arbitrary provider slices.
- [IdentityCache](<../vectorlite/src/diskann_store/identity_cache.rs#L29-L45>) uses inline 256-entry and optional 16,384-entry tables. [Clearing](<../vectorlite/src/diskann_store/identity_cache.rs#L94-L96>) touches all large-table occupancy lengths. [Every attempted write](<../vectorlite/src/diskann_store.rs#L2030-L2065>) invalidates before/after, observes read-side DML, and advances a checked mutation stamp. The stamp and cache epoch are distinct responsibilities.
- [Scalar adjacency replacement](<../vectorlite/src/diskann_store.rs#L1600-L1614>) validates owner and referenced identities, encodes neighbors, binds an UPDATE, and requires one direct changed row. [Statement cleanup](<../vectorlite/src/diskann_store.rs#L2044-L2094>) preserves the primary SQLite error.
- [Carrier boundary](<../vectorlite/src/diskann_store.rs#L646-L688>) is an ordinary two-row statement journal with pre/post guard validation, not a series of independently atomic writes. No bulk path may bypass it.
- [Optional memory admission](<../vectorlite/src/diskann_store.rs#L1687-L1734>) reserves worst-case core workspace before caches/plans and meters prepared plans with `SQLITE_STMTSTATUS_MEMUSED`. Any new epochs, buffers, iterator containers, SQL text/bindings, or plans require explicit accounting.
- [Existing adversarial tests](<../vectorlite/tests/test_diskann.py#L1284-L1427>) cover persistent/TEMP triggers, attached databases, dynamic DDL, and incremental BLOB poisoning that does not change `total_changes64`. Trigger absence or a stable change count is not a safe cache-coherence proof.
- [Existing native timer](<../benchmark/diskann_batch_benchmark.c#L211-L243>) includes BEGIN, INSERT prepare/bind/step/finalize, and COMMIT. The [paired verifier](<../benchmark/diskann_identity_benchmark.py#L349-L364>) fingerprints inputs/binaries and compares ordered graph/query data. It does not yet expose the required pager/durability grid.

Historical context only, not current measurements: [single-table read optimizations](<../plan/2026-11-11-sqlite-native-diskann-optimizations/results.md#L7-L43>) reported 1.62x on the primary workload, while a prior storage split regressed. Neither historical speedup nor old test totals are acceptance evidence for this work. Prior comparative research motivates the hypotheses; no other database's QPS claim is used as a matched insertion-speed estimate.

Subsequent valid work must succeed after the host handles that outcome. This does not extend the atomic boundary to arbitrary host-function side effects in attached/TEMP schemas. Apply the single decision table in Section 6: at **unchanged default pager settings and fixed durability**, final code achieves >=1.10x primary median paired speedup, with no reproducible >5% build/query regression. 7. All three independent reviewers approve this exact plan version; user explicitly approves it before implementation. At completion all three approve the complete integrated implementation and evidence. No majority vote or per-task approval substitutes.

A safe but insufficient speedup is a **no-ship/escalation outcome**, not success. Report the measured result and ask whether to retain a smaller improvement, change scope, or stop.
